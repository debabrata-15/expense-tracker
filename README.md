# Expense tracker

A small React + TypeScript + Tailwind CSS (v4) expense dashboard, built with Vite.
Data is saved in the browser's localStorage.

## Features

- Add and delete expenses with a description, amount, category and date
- Monthly budget with a stacked bar showing spending by category
- Browse month by month and filter the list by category
- Currency selector ($, €, £, ₹, ¥)
- Light and dark themes that follow your system setting
- Data saved in the browser's localStorage, so it survives a refresh

```bash
npm install
npm run dev      # start the dev server
```
